# MyKTV User Guide

Version 1.0

## Welcome

MyKTV helps you turn YouTube videos or local songs into karaoke-style videos with lyrics.

## What you can do

- download videos or audio from YouTube
- convert media into usable local files
- separate vocals and music
- detect lyrics automatically
- create karaoke subtitle timing
- export a finished MP4 or MKV video

## Before you start

Make sure your computer has:

- Windows 10 or newer
- enough free disk space
- a stable internet connection
- the app’s required runtime components installed

When you launch the app, it may ask you to repair or install missing components. Follow the built-in prompts.

## Main usage

### Organize your song library
1. Open the Song Library tab.
2. Select the download inbox and library folders.
3. Scan folders to index available media.
4. Edit song details and tags, then preview and confirm the destination before organizing files.

### Select and play KTV songs
1. Open the KTV Song Selection tab.
2. Browse by language, search by title or artist, or filter by tags.
3. Add songs to the queue and play a song or the queue.

### Download from YouTube
1. Paste a YouTube URL
2. Choose the format you want
3. Pick a quality such as 1080p, 720p, or 480p
4. Start the download

### Create lyrics from local video
1. Add a local video file
2. Run the recognition or vocal separation option
3. Review the generated subtitle output
4. Adjust language and timing if needed
5. Generate the final KTV-ready file

### Merge subtitles into a video
1. Open the merge tab
2. Choose your video
3. Select subtitle data
4. Choose output format
5. Start the merge process

## Tips

- For better lyric results, use clear audio and avoid very noisy recordings.
- If the app warns about missing dependencies, use the Environment Repair tab.
- GPU support can speed up processing significantly.

## Common issues

### Download fails
- Check the URL
- Make sure you have internet access
- Try again later if YouTube blocks the source

### Lyrics are inaccurate
- Use a stronger Whisper model
- Try stable-ts alignment
- Verify language settings

### Output looks stretched or not full screen
- Use the built-in 1080p force-output option

## Important note

This app creates local runtime folders and AI model folders on your machine. Keep those folders intact unless you are intentionally reinstalling dependencies.

## Summary

MyKTV is designed to make it easy to create karaoke-style videos and subtitle files from YouTube or local music sources.
