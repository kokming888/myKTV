# MyKTV UI review and remediation plan

## Scope and implementation constraints

This review covers the active local Windows desktop application: `MyKTV.py` is the Tkinter entry point, with `myktv_song_manager.py` and `myktv_ktv_selection.py` providing screen mixins. The song catalogue is a local SQLite index and playback uses the bundled FFmpeg tools. There is no implemented venue-admin interface or remote service in scope; this plan does not add one. Archived snapshots and packaged output are not implementation targets.

The remediation preserves the native Tkinter application, its existing data model, and the supported local workflows. No new dependencies are planned. Source edits and checks are recorded below as they happen. GUI behavior that cannot be exercised in this environment will remain explicitly marked for manual Windows validation.

## Current continuation status (2026-11-01)

All ten code-remediation items are implemented and have passed the documented source-level checks. The remaining Windows GUI validation is blocked in this environment: Python 3.14.10 and Python 3.12.10 are present, but neither has Pillow (`PIL`), and no dependencies were installed. The app was not launched; GUI behavior must not be considered verified.

**Next step:** run the changed source with the project's supported Windows runtime containing Pillow and the bundled FFmpeg tools, then complete the manual validation checklist below. Pay special attention to the declared 1300x760 minimum: verify it fits actual target monitors (especially 1280x720 and 1366x768); if not, implement a stacked/narrow layout rather than requiring a window larger than the available display. Do not release until the runtime checks and any needed sizing correction are recorded.

## Detailed tasks and execution status

Work is being performed in the order below, one item at a time. “Done” means the source change and the listed non-GUI validation were actually completed; it does not imply a Windows GUI check unless that check is explicitly reported.

Manual Windows ffplay verification remains outstanding.

Sizing arithmetic and `ast.parse` passed for both edited modules. Manual Windows resize/render check remains outstanding.
