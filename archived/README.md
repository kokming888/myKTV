# Archived YTToMKV Files

This folder preserves files from the previous YTToMKV identity and numbered-script release history. The active product is **MyKTV 1.0**; these archived files are not used by the current app.

## Contents

- `legacy_source/` — numbered `yt2mkv_tools2-9.py` through `yt2mkv_tools2-16.py` historical snapshots
- `legacy_packaging/` — the former `YTToMKV.spec`, generated `build/`, and generated `dist/`
- `legacy_mock/` — the earlier standalone song-library HTML mockup

The active source, MyKTV helper modules, documentation, and build specification remain in the project root.
